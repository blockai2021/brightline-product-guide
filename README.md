# Product-iCode Platform

A bilingual product information platform with an admin dashboard and consumer pages for product updates, warranty, support, and event registration.

Administrators can publish product information and release updates that appear on consumer pages. Consumers can access warranty and after-sales support flows, register for events, and manage marketing consent. The prototype supports English, Chinese, and German, with demo data stored in the current browser.
